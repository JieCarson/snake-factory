# LOF-000 贪吃蛇试产件 交付报告

## 交付清单
- `snake/index.html`：单文件贪吃蛇（原生 HTML/CSS/JS 内联，canvas 渲染，无模块/无外部依赖，`file://` 双击可玩）。20×20 棋盘，初始长 3 居中向右，150ms/格，方向键转向且禁 180° 反向，空格暂停/继续/重开，撞墙撞身结束并显示「游戏结束 得分 N / 按空格重开」。
- `snake/test.js`：核心逻辑（方向输入、走步、碰撞、食物重生）的可测副本与 10 条断言。

## 自测（node snake/test.js 真实输出）
```
PASS: 向右时按左键无效
PASS: 向右时按上键生效
PASS: 吃食物后长度 +1
PASS: 吃食物后得分 +1
PASS: 吃食物后游戏未结束
PASS: 撞右墙结束
PASS: 撞上墙结束
PASS: 撞自身结束
PASS: 追上正在移走的尾格不算撞
PASS: 食物重生 100 次均不在蛇身且在棋盘内
---
通过 10 / 失败 0
```

## 关键决策与已知限制
决策：自撞判定排除本步将移走的尾格（追尾不算撞），这是经典规则的正确边界；食物重生采用"枚举全部空闲格再随机取一"，保证永不落在蛇身且不会死循环；反向判定基于当前实际移动方向而非排队方向，避免一个 tick 内两次按键绕过 180° 限制。限制：test.js 是逻辑副本而非从 index.html 直接引用（单文件约束下无法共享模块）；速度固定不加速、无音效、无最高分记录，均为工单范围外，未实现。
